Importar Disciplinas

{% csrf_token %}
  1. Baixe o modelo de planilha CSV
    Clique no botão abaixo para baixar o arquivo de modelo. Ele contém o formato correto que deve ser seguido para importar os disciplinas.
  2. Preencha o modelo com os dados dos disciplinas
    Abra o arquivo no editor de planilhas de sua preferência (como Excel ou Google Sheets) e preencha as informações necessárias. Certifique-se de não alterar os cabeçalhos das colunas.
  3. Exporte o documento em CSV
    Busque pelas opções de exportação e selecione "CSV" como o formato de exportação.
  4. Envie o arquivo preenchido
    Após preencher e salvar o arquivo, envie-o utilizando o campo abaixo. O sistema processará o arquivo e importará os disciplinas automaticamente.

Observação: Verifique se todos os campos estão preenchidos corretamente antes de enviar para evitar erros na importação.
